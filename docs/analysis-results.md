# Analysis Results

CHEMSMART GUI displays calculation results through normalized documents
returned by the backend. The frontend presents these values as received; file
parsing, chemistry interpretation, and spectrum generation remain backend
responsibilities.

## Supported Output Documents

- Gaussian `.log` and ORCA `.out` files can be opened as calculation output
  documents.
- Optimization outputs are shown as trajectories when multiple structures are
  available.
- The trajectory panel lets users select frames, play the trajectory, and view
  scalar frame properties.
- Frequency data is attached to molecule frames when it is available in the
  parsed output.
- Output files are read-only in the application. Generated structures and
  exports create separate documents or files.

## Units and Fields

| Field | Meaning | Unit |
|---|---|---|
| `coordinate_unit` | Cartesian coordinate unit | `angstrom` |
| `energy_hartree` | Trajectory-frame electronic energy | Hartree |
| `frequency_cm_minus_1` | Vibrational frequency | cm^-1 |
| `reduced_mass_amu` | Reduced mass for a vibrational mode | amu |
| `force_constant_mdyne_per_angstrom` | Force constant for a vibrational mode | mdyne/angstrom |
| `ir_intensity_km_per_mol` | IR intensity for a vibrational mode | km/mol |
| `normal_termination` | Calculation termination status when reported | true/false |

Gaussian and ORCA outputs use the same frontend fields after backend
normalization, so tables, trajectories, and spectra do not need
program-specific frontend parsing.

## Frequencies and Modes

The vibrational mode table shows mode index, frequency, imaginary/real state,
reduced mass, force constant, IR intensity, and symmetry when those values are
available. Imaginary modes are marked from the normalized mode state.

Mode displacement vectors are shown when present. A mode can be animated or
exported as a displaced structure only when displacement vectors are available.
When displacement vectors are missing, the UI keeps the mode visible but
disables displacement-dependent actions.

## Trajectories

Trajectory frame selection changes the molecule shown in the viewer. Playback
advances through the same normalized frames. The energy profile is drawn from
numeric `energy_hartree` frame properties only. If a trajectory has no numeric
energies, the profile shows an empty state rather than converting or inferring
values.

## IR Spectra

The IR stick spectrum uses positive `ir_intensity_km_per_mol` values and
`frequency_cm_minus_1` frequencies. Selecting a stick-spectrum peak selects the
matching vibrational mode.

The broadened IR spectrum preview is generated by the backend from the
selected molecule document. Users can choose Gaussian or Lorentzian broadening
and a positive width in cm^-1. The frontend displays returned curve points and
does not broaden or normalize spectrum values itself.

Modes without positive IR intensity are skipped for IR spectra. If no positive
IR intensities are available, the spectrum panel shows an unavailable state.

## Unsupported or Missing Data

- Missing vibrational modes: the frequency panel reports that no modes are
  available.
- Missing displacement vectors: animation and displaced-structure generation
  are unavailable for that mode.
- Missing or non-positive IR intensities: those modes are not included in IR
  spectra.
- Missing numeric trajectory energies: the energy profile is not drawn.
- Invalid broadening width: the broadened spectrum preview is not requested.
- Output files: `.log` and `.out` files are never overwritten by edit or export
  actions.
