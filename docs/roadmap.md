# Roadmap

## Phase 1

- Basic molecular viewer.
- Mock document service.
- API schema.
- Electron shell.

## Phase 2

- Real CHEMSMART structure opening.
- `.xyz`, `.sdf`, `.com`, `.gjf`, `.inp` support through CHEMSMART.
- Basic geometry editing.

## Phase 3

- Gaussian/ORCA output visualization through CHEMSMART adapters.
- Frequency table.
- Normal mode animation.
- Optimization trajectory viewer.

## Phase 4

- Job builder.
- Local/HPC submission.
- Job monitoring.
- CHEMSMART database browser.
